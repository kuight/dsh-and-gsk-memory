# Runbook：与执行者 Agent 的协作规则

## 执行者模式
- 执行者只做被明确指派的事，不自行扩展范围、不"顺手优化"。
- 每步操作前说清要动哪个文件/哪个目录；动主环境前先确认。
- 有疑问先问，不猜；猜错造成的写盘代价高于一次问答。

## 汇报规则
- **汇报不超过 40 行**。超出即视为未完成汇报要求，需压缩重写。
- 结论先行，证据附后；不贴大段原始日志，只引路径 + 关键行。
- 无法完成的事直说"未执行/失败"，不模糊表述。

## 停止条件的设计原则
- 每个任务必须有**明确的停止点**（如"推送后汇报 commit 号，停止"）。
  无停止点的任务会无限延伸。
- 遇以下情况立即停止并上报，不自行继续：
  - 工具返回值与请求语义不符——继续写盘会污染文件；
  - 需要动主环境且未获授权；
  - 出现与硬规则冲突的指令。

## 新对话入口
- 新会话第一步：读 `https://raw.githubusercontent.com/kuight/dsh-and-gsk-memory/main/INDEX.md`
  再读当前 handoff（`handoffs/` 下最新一份）。
- 不要跳过 INDEX —— 里面有已证伪清单，跳过会重复排查已知问题。

## 执行规范（2026-09-28 新增）

- 工具调用默认串行。非必要不发并行块。
- 每个事实结论都必须附上产生它的命令和原始输出；没有输出的内容一律不写成结论。
- 结论与已有证据冲突时，先把输出落盘成文件，再在文件上重查，不直接采信管道输出。
- 事实分级标注：【实测】/【复核通过】/【已撤回】/【未实测】/【假设】/【未证实】（含义见文末"任务书格式"一节）。

### 工具故障的处置（2026-09-28 补记）

- 本会话实测：工具调用故障**无法提前预测**，但**可以事后识别**——判据是「返回值语义与请求不符」（如请求读文件却返回目录列表、参数被替换成无关命令）。
- 因此**不能靠“小心一点”来规避**，只能靠流程：
  - **任何写入/侧写操作后，必须用独立的只读命令复核**（`wc -l`、`grep -c`、`sed -n` 打印实际内容），**不信写入命令自己的回显**。
  - 复核发现不符时，**不要重试同一条命令**（大概率再退化），改用另一种手段（python 读写、Edit 工具）。
- 故障高发位置：**动作切换点**——一段自然语言汇报之后的第一条调用、只读转写操作处。此处尤其要复核。
- 已证伪的旧归因（勿再引用）：意图模糊、上下文过长、全角标签损坏。三者均有反例。
- **复核 agent 的结论时，先列出它当时汇报的原话，再逐条对照；不能拿 agent 自己的汇报当证据。**

### 任务书格式（2026-09-30 补记）

- 标签含义：【未实测】=没跑过命令验证；【假设】=推断；【未证实】=有线索但证据不足。
- 每份任务书结尾写"任务书结束 + 编号"标记；执行者没看到就停止，并报告收到的最后一行。
- 读文件用 Read 按 offset 分页直到 EOF，汇报写明读到第几行。
- 脚本先写成 .ps1 文件再执行，输出落盘再读；不在 bash 里内联 PowerShell。
- 预计超过 100 s 的命令改为 Start-Process 后台执行，再轮询结束标记。
- 运行 .ps1 一律加进程级 -ExecutionPolicy Bypass，本机会拒绝未签名脚本；不修改机器或用户级执行策略。

### 执行者环境与通用约束（2026-09-30 起）
- 执行者现在运行在 DSH Desktop 自己的会话里（完全权限）。它不能停止或重启 DSH Desktop，否则会把自己关掉；桌面端的退出和重启一律由用户手动做。
- 通用硬约束（任务书可写"遵守通用硬约束"，再补本任务特有的）：不读取或打印任何凭据、token、key；不打印进程命令行；未经任务书授权不启停进程、不改 ~/.dsh、%APPDATA%\dsh-desktop、防火墙和 git 配置；git 只 add 指定文件；报告不出现带 token 参数的地址；命令原样执行，偏差写明。
- 禁止进仓库：%APPDATA%\dsh-desktop 与 %APPDATA%\dsh-desktop.old-0930 的全部内容、dsh-home-017\profiles\diag-min\settings.yaml、E:\work\dump-017.txt、任何 .credentials* 文件。
- 代理端口不固定（写入时为 7897）：需要代理时从 HKCU 的 Internet Settings\ProxyServer 读取，不写死；git 推送用 git -c http.proxy=... 临时代理，不改 git 配置。
- PowerShell 自定义函数用 Verb-Noun 名字，不用单字母：单字母可能撞上内置别名（r 即 Invoke-History），别名优先于函数，任务 K2 因此整段失败。
- 记忆随任务推送：会产生新事实的任务书，最后一步由审核侧给出 2-5 行日志，执行者追加到 handoffs/worklog.md，随任务一起 commit/push，不再单开一轮写记忆；执行者自己的推断不写进日志。
